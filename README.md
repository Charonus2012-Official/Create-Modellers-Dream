A NeoForge addon for the [Create mod](https://www.curseforge.com/minecraft/mods/create) that adds a smart train dispatch and control system. Route trains between named stations with full signal compliance.

## How it works

- **Dispatcher Table** — Control block for managing train schedules
- **Track Connector** — Mark stations and connection points on rails
- **Multi-Train Support** — Dispatch multiple trains across shared networks
- **Signal Integration** — Full compliance with Create's native signal system

## Requirements

- Minecraft 1.21.1
- NeoForge 54.2.0+
- Create mod 6.0.10+

## Building

```bash
./gradlew build
```

Output JAR in `build/libs/`
